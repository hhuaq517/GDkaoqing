# 广东考情通 · 广东各地区各项目考情速查站

一个 **纯静态网页**，供广东考公机构运营使用：可以按 **地区 / 项目 / 年份 / 县区 / 关键词** 快速查找广东各地考情，内置广东省地图总览（鼠标悬停地市即显示考情）、真题索引目录、可视化导入/导出、设置等。

- 数据保存在本仓库 `data/` 下的 **JS/JSON 文件**（可手工直接改）。
- 部署到 **GitHub Pages** 免费托管，分享一个网址即可让任意设备访问。

## 二、如何部署到 GitHub Pages（免费，可分享网址）

> 只需要做一次，之后每次改数据重复“四、更新数据”即可。

1. 注册/登录 [GitHub](https://github.com)，新建一个仓库（如 `guangdong-kaoqing`，公开或私有都行）。
2. 把本文件夹里的所有内容上传到仓库根目录（可用 `git push`，或在网页上点 “Add file → Upload files” 拖拽上传）。
3. 进入仓库 **Settings → Pages**：
   - Source 选择 **Deploy from a branch**；
   - Branch 选择 `main`（或 `master`），目录 `/ (root)`；
   - 点 Save。
4. 等待 1~2 分钟，网址形如：`https://你的用户名.github.io/guangdong-kaoqing/`
   → 把这个网址分享出去即可，任何设备打开都是最新数据。

> 提示：如果仓库名不是 `guangdong-kaoqing`，网址用实际仓库名。域名可后续在 Settings→Pages 里绑定自有域名。

## 三、如何更新考情数据（两种方式）

### 方式A：直接改文件（最推荐、最快）
用记事本/VSCode 打开 `data/kaoqing.js`，按现有格式增删改一条记录，保存后重新推送到仓库即可，访客立即看到新内容。

### 方式B：网页可视化导入 → 导出 → 合并 → 推送
1. 打开网站，进入 **考情导入**，输入管理员口令（默认 `admin123`，可在设置里改）。
2. 用 **单条导入** 表单录入，或 **批量表格导入**（下载 `templates/考情导入模板.csv`，填好后上传）。
3. 点 **“导出全部数据(JSON)”** 下载 `kaoqing_导出.json`。
4. 在本项目目录运行：`node tools/merge_export.js kaoqing_导出.json`，自动重新生成 `data/kaoqing.js`。
5. 推送该文件到 GitHub → 全站更新完成。

> 导入的数据默认保存在“浏览器本地会话”，只有导出并推送后才会让所有访客看到。

## 四、如何更新真题索引

真题索引 `data/zhenti.js` 是从机构真题文件夹（如 `F:\全国处理\广东地区`）自动生成的。当本地真题文件夹有新增时：

1. 用 `tools/build_zhenti.ps1`（在装有真题文件夹的电脑上运行，会读 `F:\全国处理\广东地区`）重新生成 `data/zhenti.json`。
2. 把生成的 json 转为 `window.ZHENTI = …` 并替换 `data/zhenti.js`，推送即可。

> 真题PDF文件本身（约12GB）不上传，只上传“索引清单”，方便学员查询某地某项目有哪些年份/学科的真题可拿。

## 五、安全与设置

- 导入/编辑/设置需要管理员口令，默认 `admin123`，在 **设置** 页可修改（存于本机浏览器会话）。
- 游客只能浏览（只读）。
- 深色模式、字体、页脚说明等均可在设置页调整。
